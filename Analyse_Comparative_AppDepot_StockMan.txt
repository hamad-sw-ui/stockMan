Résumé Exécutif Ce document présente une analyse comparative exhaustive entre l'application App-Depot existante et le Cahier des Charges Fonctionnel & Technique StockMan v1.0 (RootRise Group). L'objectif est d'identifier précisément les fonctionnalités manquantes, partielles ou absentes afin d'établir un plan de développement priorisé pour atteindre la conformité complète au CDC StockMan. Synthèse & Recommandations Stratégiques 5.1 Ce que App-Depot fait déjà bien Ces éléments sont conformes ou très proches du CDC StockMan et n'ont pas besoin d'être réécrits : Stack frontend identique (React 19 + Vite + TypeScript + Shadcn + Tailwind + Zustand + Dexie.js + Recharts) Mode offline-first fonctionnel avec Service Workers et Dexie.js Paiements locaux : Cash, MTN Mobile Money, Orange Money Interface mobile-first responsive avec principe '3 clics' Rôles utilisateurs de base (Super Admin, Admin, Vendeur) Journal d'audit présent (à renforcer pour l'immuabilité) Dashboard Super Admin avec vue consolidée multi-dépôts Exports PDF/Excel pour la comptabilité 5.2 Les 5 écarts les plus critiques à combler 1.  Architecture Plugin/Core Engine :  Architecture Plugin/Core Engine — Sans ce socle, aucun module ne peut être ajouté proprement. C'est le chantier fondamental et le plus long. Multi-tenant (isolation BDD par client) — Indispensable pour le modèle SaaS. Toute l'économie du produit repose dessus. Multi-unités catalogue (6 niveaux) — C'est le différenciateur clé de StockMan sur le marché africain. Sans ça, le produit ne peut pas servir les dépôts en gros. License Manager + Plans tarifaires — Nécessaire pour monétiser et contrôler l'accès aux fonctionnalités. Conformité DGI (NUI, RCCM, numérotation séquentielle factures) — Obligation légale au Cameroun. Bloquant pour la commercialisation. 5.3 Estimation totale du travail restant Phase Effort min Effort max Dépendances Phase 1 — Core & SaaS 51 jours 74 jours Prérequis pour tout Phase 2 — Catalogue & Stock 57 jours 86 jours Après Phase 1 Phase 3 — Caisse & Facturation 43 jours 65 jours Après Phase 2 Phase 4 — Rapports & IA 62 jours 93 jours Après Phase 3 Phase 5 — Desktop & Mobile 29 jours 45 jours Après Phase 4 TOTAL ESTIMÉ 242 j 363 j ~10-14 mois (1-2 dévs) 5.4 Recommandation finale 🎯 Recommandation : App-Depot est une excellente base de départ. La stack technologique est parfaitement alignée avec StockMan. La priorité absolue est de refactoriser l'architecture vers le système de plugins et d'implémenter la couche multi-tenant avant d'ajouter tout autre module. Un MVP conforme au CDC v0.3 de StockMan est atteignable en 4-5 mois en partant d'App-Depot, contre 10-12 mois depuis zéro. © 2026 RootRise Group · Document confidentiel · StockMan v1.0
